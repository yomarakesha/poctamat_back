# Что это и что с этим делать

Ответ на «Please send the contract itself». Здесь то, по чему написаны три клиента.

| Файл | Что это |
|---|---|
| `openapi.yaml` | **Источник истины.** OpenAPI 3.1, 105 операций, 58 схем, 104 кода ошибок |
| `API-01.md` | То же прозой: соглашения, справочник кодов, идемпотентность, протокол киоск ↔ агент, инварианты |
| `tokens.json` | Дизайн-токены. Тебе не нужны, лежат для полноты |
| `BACKEND-CHANGES.md` | Список правок, на который ты отвечал. Оставлен, чтобы ответ читался рядом с вопросом |

## Твои пять пунктов уже внесены

Отвечать на них не нужно, нужно проверить, что я понял правильно:

1. **Код выдачи** возвращается один раз, в ответе на выпуск, владельцу брони.
   `POST /bookings/{id}/pickup-code/rotate` теперь `200` с `code`, а не `202` без тела.
2. **Уникальность кодов в пределах постамата** записана инвариантом в описании
   `POST /kiosk/sessions`, плюс код `CODE_SPACE_EXHAUSTED`.
3. **Блокировка терминала, а не ячейки.** `CellStatus.blocked` — только решение оператора.
   `PIN_ATTEMPTS_EXCEEDED` несёт `details.locked_for_seconds`.
4. **Break-glass** — `POST /kiosk/staff/break-glass`, challenge/response.
   `offline_ttl_seconds` в `/kiosk/context`, дефолт 86400.
5. **Дверь отчитывается агентом.** `/kiosk/sessions/{id}/door-closed` помечен как
   отображающий путь; запись события — на твоём канале.

Плюс `to_remove` в enum, поведение при `door_timeout`, `/admin/stats/attention` и
`/admin/users/{id}/reset-password` — оба ты просил, оба добавлены.

## С чего начать

```bash
# 1. Посмотреть, что контракт валиден и как выглядят ответы
npx @redocly/cli lint openapi.yaml
npx @stoplight/prism-cli@5 mock -p 4010 openapi.yaml

# 2. Сгенерировать модели и заготовки роутеров под FastAPI
npx @openapitools/openapi-generator-cli generate \
  -i openapi.yaml -g python-fastapi -o ./generated
```

Дальше — обычная работа: своя реализация, модели из генерации либо руками по схемам.

## Чем проверять, что сервер соответствует контракту

Это важнее, чем кажется: у нас три сгенерированных клиента, и расхождение в имени поля
ломает сборку, а не «выглядит иначе».

```bash
pip install schemathesis
schemathesis run openapi.yaml --base-url http://localhost:8000/api/v1 --checks all
```

Оно само сгенерирует запросы по схемам и поймает несоответствия ответов.

## Порядок, который разблокирует меня быстрее всего

Приложение сейчас работает на локальном сервере-заглушке. Чтобы переключить его на твой,
достаточно первых четырёх строк:

| # | Эндпоинты | Что откроется |
|---|---|---|
| 1 | `POST /auth/otp/request` · `/verify` · `/refresh` | Вход |
| 2 | `GET /me` · `PATCH /me` · `GET /cities` | Профиль и регионы |
| 3 | `GET /postamats` · `/{id}` · `/{id}/availability` | Главная и выбор размера |
| 4 | `POST /bookings` · `GET /bookings` · `/{id}` · `/{id}/timeline` | Бронирование и аренды |
| 5 | `POST /bookings/{id}/payments` · `GET /payments/{id}` | Оплата |
| 6 | `/deposit-code/rotate` · `/pickup-code/rotate` · `/transfer` | Коды |

Остальное — админка и киоск, они позже.

## Две просьбы

**Не подстраивай контракт под реализацию молча.** Если что-то в схеме неудобно или
неверно — напиши, я поменяю контракт, и клиенты перегенерируются. Молчаливое расхождение
обнаружится у меня как ошибка парсинга на телефоне в отделении.

**Пришли базовый URL и что уже отвечает**, даже если это три эндпоинта. Я переключу
приложение с заглушки на твой сервер и начну ловить настоящие расхождения, а не
предполагаемые.

## Мелочь, о которой стоит знать заранее

Prism монтирует пути **без** префикса `/api/v1` — он берёт их из `paths`, а базовый путь
из `servers` отбрасывает. У тебя на сервере префикс должен быть.

Ещё две вещи в контракте не для красоты: `Idempotency-Key` обязателен на всех POST,
меняющих состояние (по твоему пункту 08 я оставил единообразие — три клиента
генерируются из одного файла), и конверт ошибки один на все не-2xx. Клиенты
переключаются по `error.code`, а не по HTTP-статусу и не по тексту.
